## 🎨 Visual Direction

- **Progress bar:** morphs from flat → glowing → dynamic gradient → animated sparkles by Level 10.
- **Badges:** evolve from simple icons → metallic embossed designs → glowing sigils.
- **Background:** each new level could trigger a _slight dashboard tint or aura animation_ to signal growth subconsciously.
- **XP sound:** soft celebratory tone (like a mobile game level-up chime).

## 🧠 Psychology Behind the Progression

- **Levels 1–3** → Build trust and mastery (“I understand how this works”).
- **Levels 4–6** → Build identity and routine (“I’m consistent, I belong here”).
- **Levels 7–10** → Build legacy and community (“I help others win”).

This system mirrors _intrinsic motivation curves_ in gamification psychology (from Fogg Behavior Model and Octalysis Framework).
